# 01. 데이터와 정보 (Data & Information)

## 1. 데이터 (Data)

### 한국어

- 아직 가공되지 않은 개별적인 사실이나 값
- 데이터 자체만으로는 의미를 충분히 파악하기 어려울 수 있음
- 문맥(Context)이 추가되면 데이터의 의미를 해석할 수 있음

### 日本語

- まだ加工（かこう）されていない個々（ここ）の事実（じじつ）や値（あたい）のこと。
- データそのものだけでは、意味（いみ）を十分（じゅうぶん）に把握（はあく）することが難（むずか）しい場合（ばあい）がある。
- 文脈（ぶんみゃく）（Context）が加（くわ）わることで、データの意味（いみ）を解釈（かいしゃく）できる。

### Example

```text
user01
티셔츠
25,000
2025-05-30
```

- 각 값의 의미나 관계를 파악하기 어려움
- それぞれの値（あたい）の意味（いみ）や関係（かんけい）を把握（はあく）することが難しい。

## 2. 구조화된 데이터 (Structured Data)

### 한국어

- 일정한 형식에 따라 정리된 데이터
- 컬럼명 등을 통해 각 값의 의미를 파악할 수 있음
- 데이터를 검색하거나 분석하기 쉬워짐

### 日本語

- 一定（いってい）の形式（けいしき）に従って整理（せいり）されたデータのこと。
- 列名（れつめい）などによって、それぞれの値（あたい）の意味（いみ）を把握（はあく）できる。
- データの検索（けんさく）や分析（ぶんせき）がしやすくなる。

### Example

| 주문번호 | 고객ID | 상품명 | 수량 | 주문일자 |
|---|---|---|---|---|
| 1003 | user01 | 티셔츠 | 1 | 2025-05-30 |
| 1004 | user03 | 운동화 | 1 | 2025-05-30 |
| 1005 | user02 | 티셔츠 | 3 | 2025-05-30 |

- 데이터가 테이블 형태로 정리되어 각 값의 의미가 명확해짐
- 주문번호, 고객ID, 상품명 수량 등을 구분할 수 있음
- 특정 조건에 해당하는 데이터를 쉽게 검색하고 분석할 수 있음
- データがテーブル形式（けいしき）で整理（せいり）され、それぞれの値（あたい）の意味（いみ）が明確（めいかく）になる。
- 注文番号（ちゅうもんばんごう）、顧客（こきゃく）ID、商品名（しょうひんめい）、数量（すうりょう）などを区別（くべつ）できる。
- 特定（とくてい）の条件（じょうけん）に一致（いっち）するデータを簡単（かんたん）に検索（けんさく）・分析（ぶんせき）できる。

## 3. 정보(Information)

- 데이터를 목적에 맞게 분석·가공한 의미 있는 결과
- 필터링, 그룹화, 집계 등을 통해 얻을 수 있음
- 의사결정에 활용 가능
- データを目的（もくてき）に応（おう）じて分析（ぶんせき）・加工（かこう）した意味（いみ）のある結果（けっか）のこと。
- フィルタリング、グループ化（か）、集計（しゅうけい）などによって得（え）られる。
- 意思決定（いしけってい）に活用（かつよう）できる。

### Example

2025년 5월 30일 가장 많이 판매된 상품

- 티셔츠: 4개
- 운동화: 1개
- 결과: 티셔츠가 가장 많이 판매됨

2025年（ねん）5月（がつ）30日（にち）に最（もっと）も多（おお）く売（う）れた商品（しょうひん）

- Tシャツ：4個（こ）
- スニーカー：1足（そく）
- 結果（けっか）：Tシャツが最（もっと）も多（おお）く売（う）れた。

## Summary

- Data: 개별적인 사실이나 값
- Structured Data: 일정한 구조로 정리된 데이터
- Information: 데이터를 분석·가공하여 얻은 의미 있는 결과
- 데이터베이스는 데이터를 체계적으로 저장하고 활용하는 데 도움을 줌

- Data：個々（ここ）の事実（じじつ）や値（あたい）。
- Structured Data：一定（いってい）の構造（こうぞう）に従（したが）って整理（せいり）されたデータ。
- Information：データを分析（ぶんせき）・加工（かこう）して得（え）られた意味（いみ）のある結果（けっか）。
- データベースは、データを体系的（たいけいてき）に保存（ほぞん）し、活用（かつよう）するために役立（やくだ）つ。
